# WinTabs changelog

## 1.1.1

- Remove custom colors from outer group tabs. The active-tab color setting is unchanged.
- Remove the unused non-tabbed layout mode and leftover drag, overlay, and window-icon code.

## 1.1.0

- Add Ctrl + Win + G to create a group from the focused window and Ctrl + Win + U to unpack all groups on the current desktop.
- Allow Ungrouped to move in the outer tab row. Use odd group numbers on the primary display and even numbers on secondary displays.
- Improve the in-app user guide, including a drop table and an example of swapping tiles.

## 1.0.0

- Add named tab groups, group shortcuts, and numbered drag badges.
- Support dragging tabs and tiles across displays, including merging and swapping tiles.
- Add the offline User guide to Settings.

## 0.1.0

- Ship a per-user Windows installer.
- Group windows into tabs, with floating rules for apps and window classes.
